TACIT

Paper: TACIT: An auditable, locally deployable Python tool for LLM-assisted qualitative coding with codebook provenance Under review · SoftwareX

Zenodo recordGitHub

A desktop application for theory-driven qualitative coding of interview transcripts. Load a coding framework (or build one from literature retrieved via OpenAlex), let a language model draft the codes, review every code yourself, and get cross-tabulations, inter-rater reliability and a Gioia data structure. Models can run entirely on your own machine.

訪談逐字稿的理論驅動質性編碼工具。載入編碼框架（或從 OpenAlex 文獻建立），讓語言模型先編初稿，研究者逐筆複核，再產出交叉表、編碼者間信度與 Gioia 資料結構；模型可完全在本機執行。

Quick start 快速開始

  1. Download and unzip TACIT-v1.3.2.zip
  2. Windows: double-click launch_windows.bat · macOS: launch_mac.command · Linux: launch_linux.sh
  3. Or: pip install -r requirements.txt, then streamlit run src/app.py
  4. No model needed to try it: tick the shipped demo analyses in the sidebar

Also included 另附

  • Ships with four frameworks: Responsible Research and Innovation (Stilgoe et al., 2013), Theoretical Domains Framework (Cane et al., 2012), UTAUT (Venkatesh et al., 2003) and an ESG-disclosure probe
  • 24 synthetic demonstration interviews in English and Chinese, already coded
  • English and Traditional Chinese interface; bilingual illustrated manual
  • Automated test suite covering every module and the full interface

scpark-network

Paper: Spurious nodes and projected edges: Network construction and covariate inference in co-membership networks Major revision · Social Networks

Zenodo recordGitHub

A pipeline that builds co-affiliation networks from OpenAlex records twice — once with raw affiliation strings as nodes, once with resolved institutions — classifies each institution's location against science and technology parks, and measures how the two construction choices change network statistics and covariate inference.

從 OpenAlex 紀錄建立共同機構網絡的流程：分別以原始機構字串與消歧後的機構為節點，判定機構是否位於科學園區，並量化兩種建構方式如何改變網絡統計與共變數推論。

Quick start 快速開始

  1. pip install -r requirements.txt
  2. python prepare_data.py — decompress the deposited inputs (once)
  3. python verify.py — checks every reported figure against the paper in about a minute

Also included 另附

  • Deposited data for three runs: the full silicon-carbide population (54,671 works), a CAR-T cross-field probe, and the 5,000-work pilot
  • A fourteen-item reporting protocol for networks built from records
  • Supplementary material and all figures with their source data

Leiden Open Edition audit

Paper: Auditing an OpenAlex-based university ranking: Indicator coverage in the CWTS Leiden Ranking Open Edition Submitted · Quantitative Science Studies

Zenodo record

Code, result files and a pre-registered verification sample for an audit of the CWTS Leiden Ranking Open Edition: which share of a university's eligible output its indicators actually cover, and why.

萊頓排名開放版稽核的程式、結果檔與預先登錄的驗證樣本：大學的合格產出中，有多少真的被指標涵蓋，以及原因。

Quick start 快速開始

  1. Unzip analysis_archive_v1.2.0.zip; scripts in code/ are numbered in the order they run
  2. Population-scale scripts (31–40) need the OpenAlex snapshot of 2026-06-26 and refuse to write results if any validation gate fails
  3. MANIFEST.sha256 lets you check every file against the archive

Also included 另附

  • A blinded verification sample of 1,000 denominator records with a frozen judgment protocol
  • Supplementary package: temporal decomposition, title-language checks, rule-based classification and calibration, all figures in PDF/PNG/SVG
  • Scopus and Web of Science records are not included (licence); queries and aggregate results are

Affiliations and counting rules

Paper: When rankings become law, a few authors can change who qualifies Under review · Nature Human Behaviour

Zenodo record

University-level data and code on publications that a university holds only through authors also affiliated elsewhere: 20,492 universities, every year 2010–2025, with the detection of surge episodes and a recomputation of the Leiden Ranking under fractional and full counting.

大學僅經由跨機構雙重掛名作者而持有之論文的資料與程式：20,492 所大學、2010–2025 年逐年資料，偵測暴增事件，並以分數計數與完整計數重算萊頓排名。

Quick start 快速開始

  1. Download affiliations_counting_rules_data_code.zip and the eight leiden_pairs parts
  2. Put the parts next to the scripts and run 00_join_leiden_pairs.py (rebuilds a 530 MB array and checks its SHA-256)
  3. The README lists every script with its inputs and outputs

Also included 另附

  • University-year tables (agg_univ_year.csv), country-year tables and flows between countries
  • All 198 episodes with their classification and string checks
  • Ranking outcomes in THE and ARWU, national ranking policies, and two full university censuses
  • No author identifiers and no author-level data

Replication package for how membership in the Stanford–Elsevier ‘top 2%’ list depends on which subfield an author is assigned to, and for the institutional rules that attach pay and rewards to the list.
